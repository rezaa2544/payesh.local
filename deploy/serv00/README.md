# سرور مرکزی پایش روی serv00 (ردیف ۱۷۱)

این بسته یک **سرور همیشه‌روشن** برای پروژه راه می‌اندازد که از هر شبکه و هر کشوری در دسترس است.
روی آن همان سرور مدرسهٔ رایانه‌های مدرسه اجرا می‌شود، با این تفاوت‌ها:

- **نقطهٔ قرار است.** فهرست همهٔ سرورهای مدرسه را در `/payesh/pub/school-servers.json` می‌دهد و اعلام‌های امضاشدهٔ سرورهای مدرسه را می‌پذیرد.
- **میزبان مدرسه‌هاست** (ردیف ۱۶۷). هر مدرسهٔ پنل مالک که سرور خودش را ندارد، این‌جا سرور می‌گیرد.
- اپ‌ها نشانی آن را از پیش می‌شناسند (`https://app.payeshschool.ir`)، پس **هیچ نشانی‌ای تایپ نمی‌شود**.

| فایل | کار |
|---|---|
| `app.js` | نقطهٔ شروع Passenger روی serv00. کلیدها را از `~/.payesh.env` می‌خواند و `server/index.js` را با حالت مرکزی اجرا می‌کند. |
| `setup.sh` | نصب و به‌روزرسانی. نسخهٔ تازه را از `releases/` می‌گیرد، وب‌سایت nodejs را می‌سازد، app.js را می‌گذارد، دوباره راه‌اندازی می‌کند و بررسی می‌کند. |
| `.github/workflows/serv00-central.yml` | سه کار:<br>• بعد از هر انتشار، خودش نصب می‌کند.<br>• هر ۱۰ دقیقه پینگ می‌کند تا سرور نخوابد.<br>• هفته‌ای یک بار وارد SSH می‌شود تا حساب رایگان بعد از ۹۰ روز حذف نشود. |
| `.github/workflows/directory-mirror.yml` | هر ۱۵ دقیقه یک رونوشت از فهرست را در شاخهٔ `directory` گیت‌هاب می‌گذارد. این رونوشت برای گوشی‌هایی است که به دامنه و دیتابیس نمی‌رسند. |

## کارهای مالک (فقط یک بار)

1. **ورود به serv00:** از ایمیل فعال‌سازی serv00 این سه را بردارید:
   - نام کاربری
   - رمز
   - نام سرور، مثل `s7.serv00.com`
2. **گذاشتن رمزها در گیت‌هاب:** مخزن ← Settings ← Secrets and variables ← Actions ← New repository secret. این سه را بسازید:
   - `SERV00_HOST` = نام سرور
   - `SERV00_USER` = نام کاربری
   - `SERV00_PASSWORD` = رمز

   این دو اختیاری‌اند و برای میزبانی مدرسه‌ها لازم‌اند:
   - `PAYESH_S3_ACCESS_KEY`
   - `PAYESH_S3_SECRET`
3. **اجرای نصب:** Actions ← serv00-central ← Run workflow. در پایان باید `PAYESH-SETUP-OK` دیده شود.
   - از این به بعد سرور روی `https://<نام‌کاربری>.serv00.net` کار می‌کند.
   - در خروجی، خط `DNS: point app.payeshschool.ir (A record) to <IP>` نشانی IP را می‌گوید.
4. **وصل کردن دامنه:** در پنل دامنهٔ payeshschool.ir یک رکورد بسازید:
   - نوع: A
   - نام: `app`
   - مقدار: همان IP مرحلهٔ ۳
5. **فعال کردن دامنه روی سرور:** بعد از چند ساعت، secret `SERV00_DOMAIN` = `app.payeshschool.ir` را بگذارید و Run workflow را دوباره بزنید. این کار گواهی https را هم می‌گیرد.

## آنچه هنوز روی خود serv00 سنجیده نشده

این‌ها را `setup.sh` گزارش می‌کند و چیزی را فرض نمی‌گیرد:

- نسخهٔ Node: باید node24، یا node22 نسخهٔ ۲۲.۱۳ به بالا، باشد.
- باز شدن درگاه loopback برای مدرسه‌های میزبانی‌شده.
- رسیدن به فضای ذخیره‌سازی ابرآروان از لهستان.
- در دسترس بودن serv00 از اینترنت معمولی ایران.

**محدودیت‌های serv00 (طبق قوانین خود سرویس):**

- رایگان است و فروش یا اجاره‌اش ممنوع است. اگر روزی خدمت فروخته شود، باید سرور پولی (VPS) گرفت.
- ۵۱۲ مگابایت حافظه و ۲۰ فرایند دارد.
- اگر ۹۰ روز وارد حساب نشوید، حساب حذف می‌شود. گردش‌کار هفتگی همین را حل می‌کند.
- serv00 حق دارد حساب را بی‌دلیل ببندد.

به همین دلیل رایانهٔ مدرسه همچنان سرور محلی و پشتیبان می‌ماند و اپ‌ها هر دو را امتحان می‌کنند.
