## ۱. توپولوژی هدف

```
            ┌──────────── Cloudflare❌ ─ استفاده نمی‌شود ──────────┐
Internet ──►│  DNS/Edge (Arvan CDN + TLS)                        │
            └───────────────┬───────────────────────────────────┘
                            │
                   ┌────────▼─────────┐
                   │  LB (HA)         │  health: /healthz
                   └───┬──────────┬───┘
              API‑1 ───┘          └─── API‑2   (stateless، ≥۲ نمونه)
                   │                  │
                   └───────┬──────────┘
                    PostgreSQL (primary + standby sync/async)
                           │
              Object Storage (t/<tenant>/…)
                           │
                   Redis (کش idempotency/rate‑limit) — اختیاری v1
```

- **بدون Cloudflare** (قید کاربر). Edge باید سرویس مجاز داخلی باشد.
- API بدون حالت ⇒ نمونهٔ دوم کافی است؛ نشست در پایگاه، نه در حافظه (امروز `live.js` حالت درون‌حافظه دارد — باید حذف شود).

## ۳. failover

| نوع | مکانیزم | زمان تشخیص | زمان سوئیچ | خطر |
|---|---|---|---|---|
| نمونهٔ API | health check + LB | ~۱۰s | خودکار | نشست‌های درون‌حافظه (باید حذف شود) |
| پایگاه primary | standby + promote | ~۳۰s | دستی/نیمه‌خودکار | دوقطبی شدن (split‑brain) |
| منطقهٔ کامل | DNS + restore | ~۵min | دستی (owner) | RPO بستگی به بکاپ |
| فضای ذخیره | چند نسخه/باکت دوم | — | خودکار خواندن | تأخیر هم‌گام‌سازی |

قواعد:
1. promote پایگاه فقط با تأیید انسان در v1.
2. پس از هر failover ⇒ ابطال نشست‌ها + بازرسی audit chain.
3. تمرین failover هر فصل، گزارش خام اجباری.

## ۴. رصدپذیری

| سیگنال | آستانهٔ هشدار | اقدام |
|---|---|---|
| `sync` خطا | > ۱٪ در ۵min | هشدار + صفحهٔ وضعیت |
| صف در انتظار | > ۵۰۰ op/tenant | بررسی سرور/شبکه |
| `conflict.open` | > ۲۰/روز/مدرسه | بازبینی UX |
| تأخیر p95 | > ۲× هدف | بررسی |
| فضای دیسک پایگاه | > ۸۰٪ | گسترش |
| گواهی TLS | < ۱۴ روز | تمدید |
| audit chain شکسته | هر مورد | **P0** |
| ورود ناموفق مکرر | > ۱۰/۵min/IP | محدودیت/قفل |

- لاگ ساخت‌یافته با `tenant_id`؛ **محتوای آموزشی در لاگ نمی‌رود**.
- صفحهٔ وضعیت عمومی: فقط وضعیت، بدون نام مدرسه.
