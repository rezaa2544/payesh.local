## ۱. تصمیم مالک (ثبت‌شده)

| پرسش | پاسخ ثبت‌شده |
|---|---|
| مخزن مرجع **محصول** | `rezaa2544/payesh.local` — تنها جایی که کد محصول، آزمون، شاهد و انتشار می‌شود |
| مخزن مرجع **قانون اساسی** (Constitution) | همان `rezaa2544/payesh.local`؛ سند در `docs/cloud/` و دروازه‌ها در `.github/workflows/build.yml` + `docs/cloud/reports/evidence/*.sh` |
| مخزن دیگر (`rezaa2544/p2`) | **فقط-خواندنی / بایگانی**؛ مبنای تاریخی است، ولی هیچ‌وقت مرجع محصول یا شاهد نیست |
| گزارش‌ها و نوشن | فقط به `payesh.local` ارجاع می‌دهند (SHA، فایل شاهد، اجرهٔ CI) |

مبنای این ثبت: دستور ایستای مالک در همین نشست — «repo isolation: تنها `payesh.local`؛ `p2` فقط خواندنی» و «همه‌چیز روی `main` و همان‌جا پوش شود».

## ۳. اجرای کنترل (fail-closed)

`npm run test:boundary` — هر ارجاع تازه به مخزن دیگر یا هر مسیر بیرون از این مخزن، آزمون را قرمز می‌کند:

- فهرست مجاز ارجاع‌ها در `tests/repo-boundary.js` (`ALLOW`) نگه داشته می‌شود؛
- هر ارجاع ناشناخته به `rezaa2544/p2` یا `../p2` ⇒ شکست آزمون با نام فایل و خط.

اجرا:

```bash
npm run test:boundary     # ⇒ «N موفق · ۰ ناموفق»
```
