# ۱۱۴ — صفحهٔ دانلود و به‌روزرسانی `payeshschool.ir` روی GitHub Pages

> وضعیت: بخش ARENA انجام شد (قالب صفحه، ساخت، گردش‌کار و این سند). **انتشار و DNS = OWNER**، و فقط پس از فعال شدن دامنه.
> قالب: `site/` · ساخت: `tools/landing-114.mjs` · گردش‌کار: `.github/workflows/pages.yml` · آزمون: `tests/landing-114.js` (LP-01..08) · شواهد [S]: `reports/evidence/114-landing.txt`.
> قیدها: **بدون Cloudflare (D‑09)** و بدون سرور خودمیزبان. صفحه فقط پیوند دانلود است و هیچ دادهٔ مدرسه یا کاربری را جابه‌جا نمی‌کند.

## ۱. چه چیزی منتشر می‌شود
| فایل | محتوا |
|---|---|
| `index.html` | صفحهٔ RTL فارسی با پیوند دانلود APK، EXE و zip از ریلیز `continuous` همین مخزن (همان نام‌هایی که `build.yml` بارگذاری می‌کند) |
| `version.json` | فقط `version` و `built_at` از `releases/manifest.json` |
| `version.js` | نمایش نسخه؛ فقط درخواست هم‌مبدأ، بدون کوکی |
| `404.html`، `logo-mark.png`، `.nojekyll` | — |

صفحه هیچ اسکریپت، فونت، تصویر یا CSS بیرونی، ردیاب، کوکی یا فرمی ندارد. CSP آن `default-src 'self'` است و `unsafe-eval` و میزبان دوردست ندارد. پیوندها فقط به `https://github.com` می‌روند. تأیید اصالت فایل‌ها کار اپ است: مانیفست امضاشده و هش (ردیف ۷۸). صفحه فقط راه رسیدن به فایل است.

## ۲. گردش‌کار
- `pull_request` فقط آزمون LP و ساخت را اجرا می‌کند و چیزی منتشر نمی‌شود.
- انتشار فقط دستی است (`workflow_dispatch`)، فقط از `main`، و فقط وقتی متغیر مخزن `PAYESH_PAGES_ENABLED=true` باشد.
- فقط actionهای رسمی `actions/*` به کار می‌روند. توکن پیش‌فرض `contents: read` است و `pages: write` و `id-token: write` فقط به کار deploy داده می‌شود.
- در انتشار با GitHub Actions، فایل `CNAME` نادیده گرفته می‌شود و لازم نیست. دامنه در تنظیمات Pages مخزن ثبت می‌شود؛ به همین دلیل `site/CNAME` عمداً وجود ندارد (LP-05/LP-07).

## ۳. رکوردهای DNS (OWNER — پس از فعال شدن دامنه)
**ترتیب مهم است** تا دامنه قابل تصاحب نباشد:
1. در **تنظیمات پروفایل** GitHub (نه تنظیمات مخزن)، در بخش Pages → Add a domain، دامنهٔ `payeshschool.ir` را اضافه کنید و رکورد TXT زیر را بسازید تا Verify شود. این رکورد را **همیشه** نگه دارید.
2. در مخزن، Settings → Pages: Source را روی **GitHub Actions** بگذارید و Custom domain را `payeshschool.ir` قرار دهید.
3. رکوردهای زیر را نزد سرویس DNS دامنه بسازید. هیچ رکورد پیش‌فرض یا wildcard (`*`) نماند.
4. پس از صادر شدن گواهی (ممکن است تا ۲۴ ساعت طول بکشد)، **Enforce HTTPS** را روشن کنید.
5. متغیر `PAYESH_PAGES_ENABLED=true` را بگذارید و گردش‌کار `landing-page` را دستی اجرا کنید.

| نام | نوع | مقدار |

| @ | A | 185.199.109.153 |
| @ | A | 185.199.110.153 |

| @ | AAAA | 2606:50c0:8002::153 |
| @ | AAAA | 2606:50c0:8003::153 |

| _github-pages-challenge-rezaa2544 | TXT | مقداری که GitHub در مرحلهٔ ۱ نشان می‌دهد |

این رکوردها از مستندات GitHub برداشته شده‌اند: «Managing a custom domain» و «Verifying your custom domain». پیش از اجرا، دوباره با همان صفحه‌ها تطبیق دهید. هیچ پروکسی یا CDN واسطی در کار نیست (D‑09). `www` خودکار به دامنهٔ اصلی هدایت می‌شود.

بررسی:
```
dig payeshschool.ir +noall +answer -t A
dig www.payeshschool.ir +noall +answer -t CNAME
dig _github-pages-challenge-rezaa2544.payeshschool.ir +short TXT
curl -sI https://payeshschool.ir | head -1
```
