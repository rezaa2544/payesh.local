## ۱. خلاصه

ردیف ۱۲۳ بخش UI لایهٔ زیرساخت (ردیف ۱۲۲) و فرم ساخت مدرسه (API ردیف ۱۲۱) را به SPA پنل مالک اضافه کرد.
PR پس از CI سبز در `main` ادغام شد و ردیف در Notion **Done** است (Evidence = لینک PR).

- صفحهٔ نهم «زیرساخت» این‌ها را نشان می‌دهد: ارائه‌دهنده‌ها، سرویس‌ها با ۱۰ سنجهٔ ظرفیت/مصرف، Endpointها و سلامت، هشدارهای باز و تاریخچهٔ درخواست‌های تغییر.
- عددی که منبع ندارد «نامعلوم» نمایش داده می‌شود. Provisioning «دستی» است.
- Credential فقط به‌صورت `secret:NAME` پذیرفته می‌شود و فیلد رمز وجود ندارد.
- عملیات پرخطر دومرحله‌ای است: (۱) درخواست با بازتایپ هدف؛ (۲) تأیید فقط توسط مالک، با بازتایپ.
- Health Check دستی پیام cooldown (429) را به فارسی نشان می‌دهد.
- «ساخت مدرسه» فقط برای مالک است. کد فعال‌سازی فقط یک بار نمایش داده می‌شود و تلاش دوباره همان `provision_op_id` را می‌فرستد.
- تطبیق ۱۱۸ به‌روز شد:
  - **R09 → PASS [S]**: API و saga و فرم SPA همه آزموده شده‌اند.
  - **R08 همچنان PARTIAL [S]**: API و migration و UI هست، ولی هیچ API واقعی ارائه‌دهنده‌ای وصل نیست.
