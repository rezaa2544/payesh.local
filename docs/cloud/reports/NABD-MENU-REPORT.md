# گزارش ردیف ۱۵۱: پوستهٔ کامل «نبض» در پنل مالک، منوی کارکردی بدون تکرار و کادر رنگی نسخه

**درخواست مالک (۲۰۲۶‑۱۱‑۱۳):**
۱. پوستهٔ «نبض» پنل کاربران کامل در پنل مالک بیاید، نه فقط رنگ‌ها.
۲. منوی همبرگری/کناری بر اساس کارکرد مرتب شود (زیرساخت، پایش، مالی، کاربران، مدارس…). هیچ موردی تکراری یا جابه‌جا نباشد.
۳. نشانگر نسخه مثل چراغ «دیتابیس» کادری به رنگ وضعیت داشته باشد.

## ریشهٔ مشکل

| مشکل | علت |
|---|---|
| «نبض» ناقص | ردیف ۱۴۷ فقط رنگ‌ها و کارت‌ها را آورده بود. نوار کناری همان `NavigationRail` مادهٔ گوگل بود و تلفن نوار پایین کپسولی نداشت. دکمه‌ها، کلیدها، پنجره‌ها و جدول‌ها هم پوستهٔ نبض نداشتند. |
| منوی نامرتب | ترتیب منو همان ترتیب صفحه‌های پنل وب بود. «پرداخت‌ها» داخل «پلن‌ها» بود. سرور کمکی و کارت زیرساخت هم در «زیرساخت» بودند و هم در «تنظیمات». |
| نشانگر نسخه | فقط متن و چراغ بود، بدون قاب. |

## چه تغییر کرد

| بخش | تغییر |
|---|---|
| `owner/lib/src/menu.dart` (تازه) | گروه‌های کارکردی، هر صفحه دقیقاً یک بار: **نمای کلی** (داشبورد) · **مدارس و کاربران** (مدارس، اپراتورها، پشتیبانی) · **مالی و اشتراک** (پلن‌ها، پرداخت‌ها، سقف مصرف) · **زیرساخت و پایش** (زیرساخت، سلامت) · **گزارش و ممیزی** (گزارش‌ها، ممیزی) · **سیستم** (تنظیمات). صفحه‌های محلی فقط وقتی امکانش هست دیده می‌شوند. |
| `NabdSideNav` | همان `.sidebar` / `.navgroup` / `.navitem` نبض: عنوان کم‌رنگ برای گروه‌ها، و گرادیان اصلی با سایهٔ درخشان برای مورد فعال. در پهنای کم فقط آیکون و خط جداکننده نمایش داده می‌شود. |
| `NabdCapsuleBar` (تلفن) | کپسول شناور پایین صفحه، مثل `.bottomnav` نبض: داشبورد، مدارس، پرداخت‌ها، زیرساخت و «همهٔ بخش‌ها». کشوی گروه‌بندی‌شده با «همهٔ بخش‌ها» باز می‌شود. |
| «پرداخت‌ها» | صفحهٔ جدا در «مالی و اشتراک» (`pages/payments_page.dart`). دیگر داخل «پلن‌ها» نیست. |
| سرور کمکی | فقط در «زیرساخت» (بالای صفحه همراه کارت زیرساخت). از «تنظیمات» برداشته شد و «تنظیمات» فقط به‌روزرسانی را دارد. |
| داشبورد | کارت قهرمان «نبض پلتفرم» (`NabdHeroCard`، مثل `.nabd-card`): کاربران فعال، و تراشه‌های اشتراک‌ها، پلن‌ها و درخواست‌های باز. |
| `payesh_ui` · `theme.dart` | تم کامل نبض برای همهٔ اجزا: نوار بالا، دکمهٔ پررنگ با سایهٔ درخشان، پنجره، کلید (Switch)، نشانگر پیشرفت، خط جداکننده، جدول، راهنمای شناور. تم کلاسیک بدون تغییر است. |
| `payesh_update` · `UpdateLight` | قرص گرد با پس‌زمینهٔ کم‌رنگ و کادر به رنگ وضعیت (`update-pill-<phase>`)، مثل چراغ «دیتابیس». در همهٔ برنامه‌های نصبی. |
| نسخه | 0.9.4. |
