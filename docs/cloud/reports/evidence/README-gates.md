## سیاست SHA برای شاهدهای متنی

فایل‌های قدیمی `.txt` در این پوشه، snapshotهای تاریخی‌اند؛ افزودن SHA امروزی به آن‌ها به‌صورت بازنویسی انبوه، منشأ هر شاهد را جعل یا مبهم می‌کند. بنابراین الزام `base_sha=<40-hex>` و `date_utc=<UTC ISO-8601>` روی هر شاهد تازه یا ویرایش‌شده اعمال می‌شود، نه به‌صورت retroactive روی تمام archiveها. CI فهرست فایل‌های evidence تغییرکرده در همان اجرا را می‌سازد و `tools/check-evidence-base.cjs` را روی آن اجرا می‌کند. `tests/evidence-base-check.js` کنترل‌های منفیِ نبودن SHA و SHA کوتاه را هم اجرا می‌کند؛ حذف/خرابی فراداده در شاهد جدید باعث شکست گیت می‌شود.

برای بررسی محلی:

```sh
node tests/evidence-base-check.js
```
