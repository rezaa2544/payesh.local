## تصمیم

دروازه‌های تاریخی غیرفعال نمی‌شوند (سخت‌گیری fail-closed حفظ می‌شود)؛ فقط برچسب «شاهد تاریخی/منسوخ» می‌خورند تا خروجی دائمی `FAIL` گمراه‌کننده نباشد. خروجی آن‌ها فقط باید در بستر تاریخی خودش تفسیر شود. شاهد تاریخی مربوطه (`mission-a-pr73-integrity.txt`) حفظ می‌شود.

## آزمون
