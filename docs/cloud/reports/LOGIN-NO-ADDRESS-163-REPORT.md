# ردیف ۱۶۳ — ورود بدون کادر نشانی سرور، اتصال خودکار کاربران به دیتابیس مدرسه، صفحهٔ ورود تازه، نصب‌کنندهٔ سرور دیتابیس

**درخواست مالک (۲۰۲۶‑۱۱‑۱۵):** کادر «نشانی سرور مدرسه» در صفحهٔ ورود بی‌معنی است و باید حذف شود؛ چرا وصل نمی‌شود درحالی‌که دیتابیس در پنل مالک وصل است؛ اتصال کاربران به دیتابیس را تنظیم و تأیید کن؛ همهٔ فایل‌های نصبی به‌روز شوند؛ صفحهٔ ورود بسیار زیباتر شود.

## علت ریشه‌ای «وصل نمی‌شود»
- پنل مالک مستقیم با دیتابیس ابری (Arvan S3) حرف می‌زند، ولی اپ مدرسه طبق D‑23/D‑36 هیچ کلیدی ندارد و همهٔ داده را از **سرور مدرسه** می‌گیرد.
- روی رایانهٔ مدرسه فقط نصب قدیمی 0.9.2 بود که سرورش را پنجرهٔ قدیمی (`desktop\Payesh.exe`) روشن می‌کرد؛ گزینهٔ اجرای خودکار انتخاب نشده بود و از وقتی مدرسه به اپ بومی رفت هیچ‌کس سرور را روشن نمی‌کرد ⇒ اپ هیچ سروری پیدا نمی‌کرد.
- نصب‌کنندهٔ «سرویس دادهٔ مدرسه» (`payesh-data-service-setup.exe`) فقط در CI ساخته می‌شد و منتشر نمی‌شد.

## تغییرها (v0.9.17، main)
| بخش | تغییر |
|---|---|
| صفحهٔ ورود | کادر نشانی سرور و متن راهنمای آن حذف شد (`lan-server`/`lan-help` دیگر وجود ندارد)؛ نشانی هم نمایش داده نمی‌شود. |
| پیدا کردن سرور | `SessionController._findLan`: ① سرور به‌خاطرسپرده + همین رایانه (هم‌زمان) ② اگر سرور روی همین رایانه نصب ولی خاموش است، `LocalSchoolServer` روشنش می‌کند (تسک `PayeshDataService` یا `server\start.js` نصب قدیمی با همان پوشهٔ داده) و تا ۳۰ ثانیه صبر می‌کند ③ فهرست نشانی‌ها در دیتابیس مالک. |
| فهرست نشانی‌ها | `server/discovery.js`: هر سرور مدرسه هر ۵ دقیقه `payesh/pub/school-servers.json` را (فقط نشانی‌های شبکهٔ خصوصی + نشانی https عمومی، نام مدرسه، نسخه) با `public-read` می‌نویسد؛ بقیهٔ دیتابیس خصوصی (403). اپ با یک GET ساده می‌خواند (`school_finder.dart`)؛ نشانی فهرست با `--dart-define=PAYESH_SERVERS_URL` در ساخت CI داده می‌شود (نگهبان D‑36 دست‌نخورده). |
| وضعیت اتصال | نوار بالای کارت: «وصل به دیتابیس مدرسه · نام مدرسه» / «در حال اتصال…» / «اتصال به دیتابیس مدرسه برقرار نشد» + «تلاش دوباره». دکمهٔ ورود منتظر جست‌وجو می‌ماند؛ اگر سروری نبود پیام روشن فارسی و هیچ درخواستی فرستاده نمی‌شود. |
| طراحی | `login_brand.dart`: پس‌زمینهٔ گرادیان نبض با هاله، معرفی پایش کنار کارت (رایانه ≥۹۰۰) یا بالای آن (گوشی)، کارت سفید گرد، زبانه‌های «نام کاربری و رمز» / «شماره و کد پیامکی»، فیلدهای آیکون‌دار، نمایش/پنهان رمز، دکمهٔ اصلی گرادیان. |
| https | `LanServerRules.allowed`: http فقط شبکهٔ محلی؛ https (تونل خود سرور) مجاز؛ زنجیرهٔ Let's Encrypt همراه اپ (`le_trust.dart`). |
| نصب‌کننده‌ها | `payesh-data-service-setup.exe` روی کانال جدای `school-server-continuous` منتشر می‌شود (پس از نصب/آزمون/حذف در CI، بررسی هش پس از بارگذاری)؛ README پیوند مستقیم؛ رجیستری ۱۲۵ `published-server`؛ نصب‌کنندهٔ اپ بومی/APK/پنل مالک با نسخهٔ تازه. |

## نکته‌های باز
- پروفایل Wi‑Fi این رایانه «Public» است؛ قاعدهٔ فایروال سرویس داده فقط Private/Domain است و فعلاً قاعدهٔ قدیمی «Payesh Local» (Any) دسترسی دستگاه‌های دیگر را باز نگه می‌دارد. پیشنهاد: Wi‑Fi مدرسه را «Private» کنید.
- اگر چند مدرسه در فهرست باشند، اپ اولین سرور پاسخ‌دهنده را برمی‌گزیند؛ سرور به‌خاطرسپرده همیشه اول است.
