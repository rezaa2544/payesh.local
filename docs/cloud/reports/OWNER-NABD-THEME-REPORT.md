# گزارش ردیف ۱۴۷: پوسته و رابط پنل مالک بومی = «نبض» پنل کاربران

**درخواست مالک (۲۰۲۶‑۱۱‑۱۰):** پوسته و رابط کاربری پنل مالک مثل پوستهٔ پنل کاربران («نبض») باشد.

**منبع طرح:** `client/pulse.css`، منبع توکن‌های «نبض». پنل مالک وب (`apps/owner-panel/web/app.css`) از قبل همین ظاهر را داشت. این ردیف پنل مالک **بومی** (Windows/Android) را هم‌شکل کرد.

## چه تغییر کرد

| بخش | تغییر |
|---|---|
| `payesh_ui` | ظاهر انتخابی `PayeshLook { classic, nabd }` اضافه شد، با توکن‌های `PayeshTokens.nabdLight` و `nabdDark` (همان متغیرهای pulse.css در حالت روشن و تیره). `PayeshUi.light/dark(look:)` و `PayeshMaterialApp(look:)` آن را می‌گیرند. ابزارهای تازه: `PayeshBackdrop` (پس‌زمینهٔ `body` نبض با هالهٔ فیروزه‌ای و کهربایی) و `PayeshBrandMark` (نشان روی گرادیان اصلی). |
| ظاهر «نبض» | گوشهٔ کارت و دکمه ۱۸. کارت‌ها سایهٔ نرم فیروزه‌ای دارند. مورد فعال منوی کناری و کشویی با رنگ اصلی پر می‌شود و نمادش سفید است (`.navitem.active`). عدد کاشی‌های آمار به رنگ اصلی است (`.stat b`). حاشیهٔ فیلد در حالت فوکوس به رنگ اصلی است (`--ring`). |
| پنل مالک بومی | `look: PayeshLook.nabd`. صفحه‌های ورود (سروری و محلی) و پوستهٔ اصلی پس‌زمینهٔ نبض دارند. بالای منوی کناری و کشو نشان برند و «پنل مالک پایش» آمده، مثل `.brand` نسخهٔ وب. صفحهٔ ورود هم نشان برند دارد. همهٔ کلیدهای آزمون (`nav-rail`، `nav-drawer`، `account-menu`، `mode-badge`، `db-light`، `update-light`، `theme`، …) ثابت ماندند. |
| دسترس‌پذیری | دو رنگ روشن pulse.css معیار AA را رد می‌کنند: `--muted #5d7d76` (۴٫۳۳:۱ روی پس‌زمینه) و `#0d9488` (روی سفید). در توکن‌ها تیره‌تر شدند: `#4f6f68` و `#0f766e`. رنگ `#0d9488` فقط آغاز گرادیان ماند. همهٔ متن‌ها، نشان‌ها، دکمه‌ها و نماد منوی فعال در روشن و تیره ≥ ۴٫۵:۱ هستند. |
| برنامهٔ کاربر بومی | دست نخورد. پیش‌فرض `classic` است و طلایی‌های قبلی بایت‌به‌بایت یکسان ماندند. |
