## ۱. خلاصه

- اپ بومی Flutter مدرسه (Android + Windows) حالا علاوه بر Gateway ابری، مستقیم به **سرور خود مدرسه در شبکهٔ محلی** وصل می‌شود.
  - پروتکل همان Sync v1 است (`/api/v1/pull`، `/api/sync`).
  - ورود همان ورود سرور مدرسه است: گوشی + رمز. توکن دستگاه هم چرخشی است.
  - صندوقچهٔ پایدار (SQLite outbox) و AutoSync همان قبلی‌اند. آفلاین بودن کاربر را از حساب بیرون نمی‌کند.
- سرور مدرسه حالت **بی‌رابط** گرفت (`PAYESH_HEADLESS=1`):
  - فقط API ارائه می‌دهد. هر مسیر دیگری (`/`، `/index.html`، `/install`، `/downloads/…`، `/app.js`، …) پاسخ JSON با کد ۴۰۴ و خطای `no_web_ui` می‌گیرد و **هیچ HTML** برنمی‌گردد.
  - راه‌اندازی اولیه فقط از خود سرور (loopback) ممکن است. از شبکه پاسخ ۴۰۳ با خطای `setup_local_only` برمی‌گردد.
- **نصب‌کنندهٔ اختیاری Windows:** `payesh-data-service-setup.exe`.
  - سرویس داده را به‌صورت وظیفهٔ زمان‌بوت با حساب SYSTEM اجرا می‌کند: بدون پنجره، بدون محدودیت زمانی، با ۹۹ بار راه‌اندازی مجدد.
  - قانون فایروال فقط برای پروفایل‌های private و domain روی پورت TCP 8080 باز می‌شود.
  - با حذف برنامه، دادهٔ مدرسه **باقی می‌ماند**.
  - ISCC بستهٔ ورودی (stage) را رد می‌کند اگر `client\index.html`، `client\app.js` یا `WebView2Loader.dll` داشته باشد.
  - این نصب‌کننده هیچ مرورگر، WebView2 یا صفحهٔ وبی ندارد.
- `install/linux/install.sh` و `start.sh` هم بی‌رابط شدند. رابط وب دیگر کپی نمی‌شود و نصب قبلی‌ای که `client/` داشته پاک‌سازی می‌شود، بدون دست زدن به `data/`.
- **چیزی بی‌صدا تغییر نکرد:** سرور در حالت پیش‌فرض (بدون `PAYESH_HEADLESS`) هنوز کلاینت وب قدیمی را سرو می‌کند، چون نسخهٔ WebView منتشرشده تا ردیف ۱۲۹ به آن نیاز دارد. آزمون LM-01e همین را قفل می‌کند.

## ۶. امنیت

- **HTTP فقط داخل شبکهٔ محلی.** `LanServerRules` فقط این نشانی‌ها را می‌پذیرد: 10/8، 172.16/12، 192.168/16، 169.254/16، loopback، ULA (fc00::/7)، link-local، `.local` و نام تک‌بخشی.
  - نشانی دارای userinfo یا path رد می‌شود.
  - اندروید نمی‌تواند cleartext را به بازهٔ IP محدود کند، پس **خود اپ** پیش از هر درخواست این بررسی را انجام می‌دهد (جهش M06).
- **کلیدهای جدا.** کلیدهای LAN (`lan.*`) از کلیدهای Gateway جدا هستند. قوانین HTTPS حالت Gateway (`SchoolAccessRules`) دست نخوردند.
- **راه‌اندازی فقط از خود سرور.** هیچ‌کس از شبکه نمی‌تواند پیش از مدیر، مدرسه را «تصاحب» کند.
- **چرخش توکن.** استفادهٔ دوباره از توکن قدیمی پس از مهلت، دستگاه را باطل می‌کند و اپ به صفحهٔ سرور برمی‌گردد.
- **فایروال.** شبکه‌های public باز نمی‌شوند.
