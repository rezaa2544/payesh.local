## ۲. ریشهٔ مشترک B‑6، B‑7، B‑12

```js
// server/index.js:47
const BACKUP_ROLES = new Set(['manager', 'teacher', 'counselor', 'guard']);

// server/index.js:558-561
const backupPath = /^\/api\/admin\/(mirror|restore|backups\/daily)/.test(p);
if (p.startsWith('/api/admin/') && actor.role !== 'manager' && !(backupPath && BACKUP_ROLES.has(actor.role))) {
  return json({ ok: false, error: 'forbidden' }, 403);
}
```

یک تصمیم محصولی («عوامل اجرایی هم باید بتوانند در صورت خرابی، بکاپ بگیرند») به یک **مسیر ارتقای نقش** تبدیل شده است: بکاپ شامل کل داده و بازیابی شامل کل داده است، پس «اجازهٔ بکاپ» عملاً یعنی «اجازهٔ نوشتن همه‌چیز».

**قاعدهٔ مقصد:** «بکاپ گرفتن» و «بازیابی کردن» دو مجوز جدا هستند و هیچ‌کدام برای نقش‌های غیرمدیر مجاز نیست. بازیابی باید مستقل از مسیر داده‌ای باشد که می‌تواند نقش را تغییر دهد (مثلاً بازیابی هرگز ستون `role` را از فایل قدیمی نمی‌پذیرد).
