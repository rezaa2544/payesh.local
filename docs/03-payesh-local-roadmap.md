# سند ۳ — دامنه، فازبندی و برنامهٔ اجرای پایش-لوکال

---

## ۱. اصل حاکم بر دامنه

> نسخهٔ اول باید **یک روز کامل مدرسه** را اداره کند، نه اینکه همهٔ ۹۱ ماژول را داشته باشد.

معیار «روز کامل مدرسه»: صبح مدیر وارد شود ⇒ دبیر کلاسش را ببیند ⇒ حضور ثبت شود ⇒ نمره/تکلیف ثبت شود ⇒ غیبت و اطلاعیه به ولی برسد ⇒ مدیر گزارش روز را ببیند ⇒ شب بکاپ سالم گرفته شود. **هر چیزی که در این مسیر نیست، فاز بعد است.**

## ۲. دامنه: سه حلقه

### حلقهٔ ۱ — هستهٔ اجباری (v1)
| حوزه | ماژول |
|---|---|
| راه‌اندازی | تعریف مدرسه، سال تحصیلی، کلاس/درس، ورود اکسل دانش‌آموز و کادر، کاربران و نقش‌ها |
| هویت | پیوند دستگاه + PIN + مدیریت دستگاه‌ها |
| روزمره | زنگ، برنامهٔ هفتگی، حضور و غیاب (۳ مسیر)، حضور کادر |
| آموزش | نمره (۲۰/توصیفی/پودمان)، صف تأیید، کارنامه و ۴ گزارش وزارتی + چاپ |
| خانواده | اطلاعیه، اعلان، مرخصی، پنل ولی و فرزندان |
| انضباط | پروندهٔ انضباطی، پیگیری الگوها |
| عملیات | همگام‌سازی، بکاپ/بازیابی، سلامت، دیاگ، audit |
| نصب/توزیع | صفحهٔ نصب، APK دبیران، PWA اولیا |

### حلقهٔ ۲ — اختیاری بر اساس نوع مدرسه (v2)
- **شهریه‌دار:** شهریه، اقساط، تخفیف، بدهی، گزارش وصول (بدون درگاه پرداخت).
- **دارای مشاور:** صف ارجاع، پروندهٔ مشاوره، یادداشت محرمانه.
- **ابتدایی:** دوجو/امتیاز رفتاری.
- **هنرستان:** نمرهٔ عملی، کارآموزی.
- **شبانه‌روزی:** خوابگاه، وعدهٔ غذا، مرخصی.
- **دارای سرویس:** مسیر، راننده، سوار/پیاده.
- **چندپایه/روستایی:** نمای ماتریسی چندپایه.
- **کتابخانه/اموال/مراجعین:** نسخهٔ سبک.

### حلقهٔ ۳ — حذف در لوکال
superadmin، edu_office و تمام ساختار جغرافیایی، اشتراک/پی‌وال، پرداخت آنلاین، موتورهای هوشمندی ملی، multi-tenant، DR، WAF/canary، ۱۸ موتور تحلیلی غیرلازم، تیکت پشتیبانی سکو.

## ۳. تعریف MVP (چیزی که «کار می‌کند» یعنی)

> **۴۰ دبیر، به مدت ۲ هفته، حضور ۶ زنگ در روز را با گوشی ثبت کنند؛ یک قطعی Wi-Fi و دو قطع برق رخ دهد؛ هیچ رکوردی گم نشود و مدیر بتواند گزارش روزانه و کارنامه بگیرد.**

معیارهای پذیرش MVP:

| # | معیار | سنجش |
|---|---|---|
| ۱ | ثبت حضور هر کلاس زیر ۳۰ ثانیه | کرنومتر روی ۵ دبیر |
| ۲ | صفر رکورد ازدست‌رفته در قطعی شبکه | قطع عمدی Wi-Fi وسط ثبت + مقایسهٔ شمارش |
| ۳ | بازیابی کامل از بکاپ | restore روی سیستم دوم + تطبیق شمارش رکوردها |
| ۴ | ورود بدون پیامک | ۱۰ کاربر واقعی با کارت پیوند |
| ۵ | اسکوپ درست | دبیر A نتواند نمرهٔ کلاس B را ببیند (آزمون منفی) |
| ۶ | کارنامهٔ درست | مقایسهٔ دستی ۵ کارنامه با محاسبهٔ کاغذی |
| ۷ | نصب آسان | یک نفر غیرفنی، APK را از QR نصب کند |

## ۴. فازها

### فاز ۰ — پایه (۱ هفته)
- فورک مخزن، حذف ماژول‌های ملی از `NAV` با یک پرچم `LOCAL_PROFILE`.
- اسکلت سرور لوکال + SQLite + `records` + `/api/health` + سرو `index.html`.
- اجرای کلاینت روی LAN (بدون احراز) و دیدن اینکه حالت سروری فعال می‌شود.
- تصمیم‌های سند ۲، بخش ۱۷.
**خروج:** یک گوشی در Wi-Fi مدرسه، آیکون برنامه را باز می‌کند و به سرور وصل است.

### فاز ۱ — هویت و دادهٔ واقعی (۱–۲ هفته)
- Pairing (QR/کد یک‌بارمصرف) + PIN + نشست + جدول دستگاه‌ها + ابطال.
- `/api/v1/pull` و `/api/sync` با gate نقش/فیلد از `authz/write-perms.json`، idempotency، OCC، tombstone، audit.
- ورود اکسل واقعی مدرسه (دانش‌آموز/کادر/والد)، تعریف کلاس/درس/برنامه/زنگ.
- چاپ کارت‌های پیوند (PDF با QR) از پنل مدیر.
**خروج:** ۱۰ کاربر واقعی وارد می‌شوند؛ مدیر دادهٔ مدرسه را می‌بیند.

### فاز ۲ — هستهٔ روزمره (۲–۳ هفته)
- حضور سه‌مسیری + اصلاح با دلیل + حضور کادر.
- نمره + صف تأیید + کارنامه + ۴ گزارش + چاپ.
- اطلاعیه/اعلان/مرخصی + پنل ولی و سوییچ فرزند.
- انضباط + پیگیری الگوها.
- «حالت آفلاین» تست‌شده (صبح بدون اینترنت و حتی بدون سرور موقت).
**خروج:** معیارهای MVP.

### فاز ۳ — عملیات و پایداری (۱ هفته)
- بکاپ ساعتی/روزانه/شبانه ابری + UI بازیابی + تمرین restore.
- سرویس خودکار، UPS، سلامت و هشدار، NTP/اختلاف ساعت.
- APK دبیران + صفحهٔ نصب + QR در کلاس‌ها.
- مستند یک‌صفحه‌ای برای اپراتور و کلیپ ۳ دقیقه‌ای آموزش دبیر.
**خروج:** مدرسه می‌تواند یک هفته بدون حضور شما کار کند.

### فاز ۴ — ماژول‌های اختیاری و اولیا از خانه (۲–۴ هفته)
- ماژول‌های حلقهٔ ۲ بر اساس نوع مدرسه.
- تونل ابری + دامنه + HTTPS برای اولیا؛ یا صرف‌نظر کردن.
- آداپتور پیامک: خروجی CSV «شماره + متن ۷۰ کاراکتری» برای پنل پیامکی موجود مدرسه؛ در آینده درگاه واقعی.
- آداپتور سیدا: خروجی اکسل استاندارد.

## ۵. برآورد کار

| بخش | ساعت |
|---|---|
| سرور هسته (schema، auth، sync، pull، audit) | ۸۰–۱۲۰ |
| اصلاح کلاینت (پرچم لوکال، زمان سرور، UI پیوند/PIN/QR، حذف ماژول‌ها) | ۶۰–۱۰۰ |
| بسته‌بندی و عملیات (سرویس، بکاپ، آپدیت، سلامت) | ۳۰–۵۰ |
| APK + توزیع | ۲۰–۴۰ |
| گزارش/چاپ/اکسل با دادهٔ واقعی | ۳۰–۵۰ |
| آزمون میدانی، آموزش، مستند | ۴۰–۶۰ |
| **جمع v1** | **۲۶۰–۴۲۰ ساعت** |

با کار متمرکز: **۶ تا ۱۰ هفتهٔ کاری**؛ به‌صورت پاره‌وقت: ۳–۴ ماه. ماژول‌های اختیاری هرکدام ۱۰–۳۰ ساعت.

## ۶. ریسک‌ها و پاسخ

| ریسک | اثر | پاسخ |
|---|---|---|
| Wi-Fi ضعیف/AP Isolation | توقف عملیات | پیش‌بینی ۳ نقطه، تست صبح اول، خاموش کردن isolation، کش آفلاین |
| قطع برق | خرابی/ازدست‌رفتن داده | UPS + WAL + بکاپ ساعتی + سرویس خودکار |
| گم‌شدن/دزدی سیستم | افشای دادهٔ دانش‌آموز | رمزنگاری دیسک + رمز بکاپ + بکاپ ابری |
| مقاومت دبیران | بازگشت به کاغذ | ثبت زیر ۳۰ ثانیه، آموزش ۳ دقیقه‌ای، شروع با ۳ دبیر داوطلب |
| ساعت اشتباه گوشی | انتخاب کلاس غلط | اختلاف‌سنجی با `server_time` و اجبار در حالت سروری |
| گوشی آیفون | نصب PWA سخت‌گیر | APK برای اندروید؛ برای iOS فقط HTTPS یا تبلت مشترک |
| دادهٔ اکسل ناسازگار (سیدا) | ورود ناقص | ویزار موجود + گزارش خطای صریح + ورود مرحله‌ای |
| یک نفر برای نگهداری | توقف پس از رفتن او | مستند یک‌صفحه‌ای + بکاپ خودکار + دسترسی مدیر دوم |
| تغییر سال تحصیلی | از دست رفتن سابقه | آرشیو سال + آزمون restore |
| انتظار «همهٔ ۸۱ ماژول از روز اول» | پروژه تمام نمی‌شود | حلقه‌بندی دامنه در همین سند، به‌عنوان قرارداد |

## ۸. سه کار اول (به‌محض تأیید)

1. **فورک + پرچم لوکال:** حذف ماژول‌های ملی از منو، ساخت اسکلت سرور و اجرای کلاینت روی LAN (فاز ۰).
2. **ورود اکسل واقعی:** استخراج دادهٔ مدرسهٔ شما و اجرای مسیر import تا ببینیم نگاشت ستون‌ها با فایل واقعی سیدا/مدرسه درست کار می‌کند.
3. **آزمون میدانی حضوری:** سه دبیر، یک کلاس، سه زنگ، روی گوشی خودشان — قبل از نوشتن هر چیز دیگر. اگر این جریان روان نباشد، هیچ‌چیز دیگری مهم نیست.

---

## ۹. تعریف «پایان» برای یک سال تحصیلی

- ۹۸٪ زنگ‌ها حضور ثبت‌شده دارند.
- کارنامهٔ همهٔ کلاس‌ها از سیستم چاپ شده است.
- سه بکاپ مستقل (محلی، USB، ابری) از پایان سال وجود دارد و یک‌بار restore تست شده.
- مدیر بدون کمک شما می‌تواند سال را ببندد و سال بعد را باز کند.
- هیچ دادهٔ دانش‌آموزی در هیچ دستگاه شخصی، بعد از تحویل سال، باقی نمانده است.
