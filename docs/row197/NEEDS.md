# ردیف ۱۹۷ — نیازسنجی واقعی همهٔ مدارس ایران (مرجع آزمون و اصلاح)

> هدف: هر قابلیت پایش در برابر «نیاز واقعی» هر نوع مدرسه، هر شیوهٔ مدیریت، هر نقش و هر ماه سال
> سنجیده شود. منابع: ۱۴ پروندهٔ پژوهشی ارسالی کاربر (سند جامع، تحلیل نظام آموزشی، وظایف مدیر،
> عوامل اجرایی، نیاز دانش‌آموز/ولی، رؤسای ادارات، رقبا، بازار جهانی، کسب‌وکار، ردیاب نکات باز)
> + جست‌وجوی اینترنتی تازه (آبان ۱۴۰۵). این سند معیار پذیرش آزمون‌های ردیف ۱۹۷ است.

## ۱. انواع مدرسه و شیوهٔ مدیریت (به‌روز ۱۴۰۵)

| نوع / شیوه | ویژگی واقعی | پیامد اجباری در پایش |
|---|---|---|
| دولتی عادی | رایگان، ثبت‌نام بر پایهٔ محدودهٔ سکونت، بیشترین جمعیت | هیچ وجه اجباری؛ «شهریه» خاموش؛ فقط «کمک داوطلبانه» |
| **هیئت امنایی** (طبق آیین‌نامهٔ مشارکت‌های مردمی ۱۴۰۵ ⇒ همهٔ مدارس دولتی) | هیئت امنا = مدیر + نمایندهٔ شورای دبیران + رئیس انجمن اولیا + معتمدان؛ **دریافت شهریه ممنوع** (بخشنامهٔ تیر/مرداد ۱۴۰۵)، ثبت‌نام بی‌پیش‌شرط از محدوده | نهاد «هیئت امنا» با جلسه/مصوبه/صورتجلسه؛ ثبت کمک داوطلبانه + رسید؛ هیچ اجبار پرداخت به ولی |
| غیردولتی (غیرانتفاعی) | مؤسس/هیئت مدیره، شهریهٔ مصوب، آزمون ورودی خودشان، پاسخگویی دوگانه (مؤسس + اداره) | ماژول شهریهٔ کامل، قیف پیش‌ثبت‌نام، گزارش برای مؤسس |
| نمونه دولتی / سمپاد (استعدادهای درخشان) | آزمون ورودی (پایهٔ هفتم و دهم)، رایگان | ثبت نتیجه/رتبهٔ آزمون ورودی |
| شاهد و ایثارگران | بخشی از دانش‌آموزان شاهد (معاف)، بقیه با شرایط | وضعیت مالی/اولویت **در سطح دانش‌آموز** نه مدرسه |
| استثنایی | کلاس ۴ تا ۷ نفر (چندمعلولیتی/اوتیسم ۳ تا ۵)، چندپایه حداکثر ۳ پایه، IEP، کاردرمان/گفتاردرمان | پروندهٔ IEP با کمترین دسترسی، نقش کارکنان کمکی |
| روستایی / عشایری / چندپایه | حداکثر ۳ پایه و ۱۵ نفر در یک کلاس (آیین‌نامهٔ ۸۹۵)، مدیرآموزگار، اینترنت ضعیف | کلاس با چند پایه، معلم همهٔ دروس، کار کامل آفلاین |
| شبانه‌روزی | خوابگاه، وعدهٔ غذا، مرخصی آخر هفته، ایمنی شبانه | ماژول خوابگاه و مرخصی رفت‌وبرگشت |
| هنرستان فنی‌وحرفه‌ای / **کاردانش** | **ارزشیابی پودمانی**: هر درس تخصصی ۵ پودمان؛ نمرهٔ پودمان = شایستگی (۱/۲/۳)×۵ + مستمر (۰ تا ۵ با گام ۰٫۵)؛ قبولی هر پودمان ≥ ۱۲؛ نمرهٔ درس = میانگین پودمان‌ها؛ پودمان مردود ⇒ «ناتمام» و ارزشیابی مجدد در بازهٔ پودمان بعد؛ کارآموزی با ساعت | ثبت نمرهٔ پودمانی، هنرآموز، ناظر کارآموزی، کارگاه/تجهیزات |
| بزرگسالان / شبانه / از راه دور | کلاس فشرده، شرایط سنی | پایه/برنامهٔ انعطاف‌پذیر |
| دونوبته (صبح/عصر) | دو مدرسه یا دو نوبت در یک ساختمان؛ تعطیلی‌ها «در دو نوبت صبح و عصر» اعلام می‌شود | نوبت کاری در برنامه و حضور |
| دیگر عناوین | قرآنی، معارف اسلامی، ورزش، اقلیت‌های دینی، سما، ماندگار، وابسته | برچسب نوع + قواعد مالی/پذیرش |

## ۲. مقطع‌ها و قواعد ارزشیابی

- **ابتدایی:** ارزشیابی کیفی‌ـ‌توصیفی (فرم توصیف عملکرد + مقیاس رتبه‌ای: خیلی خوب / خوب / قابل قبول / نیاز به تلاش بیشتر)؛ از ۱۴۰۵ امتحان هماهنگ پایهٔ ششم لغو. معلم واحد همهٔ دروس یک کلاس ⇒ «نمره از ۲۰» برای ابتدایی غلط است.
- **متوسطه اول:** نمره از ۲۰، دو نوبت؛ پایهٔ نهم ⇒ **هدایت تحصیلی** (عملکرد ۳۵٪، آزمون‌های مشاوره‌ای ۳۰٪، نظر دانش‌آموز ۱۰٪، معلمان ۱۰٪، مشاور ۱۰٪، ولی ۵٪؛ نتیجه در my.medu.ir).
- **متوسطه دوم نظری:** نوبت اول (دی) و دوم (خرداد)، مستمر + پایانی؛ **امتحان نهایی** پایهٔ یازدهم (۶ درس) و دوازدهم؛ در ۱۴۰۵ نوبت اول دوازدهم هم نهایی کشوری؛ غیبت غیرموجه در امتحان ⇒ «غ» و صفر.
- **هنرستان/کاردانش:** پودمانی (بالا) + دروس عمومی عادی.
- **انضباط:** کسر برای تأخیر/غیبت غیرموجه، پروندهٔ انضباطی سطح‌بندی‌شده، ارجاع به شورای مدرسه.

## ۳. نقش‌ها و نیاز واقعی (خلاصهٔ آیین‌نامهٔ اجرایی مدارس ۱۴۰۰ + پژوهش‌ها)

| نقش | باید بتواند |
|---|---|
| مدیر | ثبت‌نام/کلاس‌بندی، برنامهٔ هفتگی، **حضور و غیاب کارکنان**، جایگزینی دبیر غایب، شوراها (معلمان، دانش‌آموزان، مدرسه، انجمن اولیا، هیئت امنا) با صورتجلسه، مالی (شهریه یا کمک داوطلبانه)، مانور ایمنی سالانه، آموزش ضمن خدمت، ارزشیابی معلم (نظرسنجی ناشناس)، گواهی‌ها، **تأیید مرخصی**، گزارش قابل انتشار |
| معاون آموزشی | برنامهٔ درسی، امتحانات داخلی، نظارت نمره |
| معاون اجرایی | پرونده‌ها، ثبت‌نام، سناد، بایگانی، ثبت نمرات پودمانی در سناد |
| معاون پرورشی/انضباطی | انضباط، رویدادها، مراسم |
| مشاور | پروندهٔ مشاوره، **شاخص ریسک**، هدایت تحصیلی، جلسه با ولی، جست‌وجوی دانش‌آموز |
| دبیر / آموزگار / هنرآموز | حضور زنگ جاری، نمره (یا توصیفی یا پودمانی)، یادداشت/انضباط، تکلیف، پیام به ولی، ارجاع به مشاور |
| دانش‌آموز | برنامه، نمره، حضور، تکلیف، شمارش معکوس امتحان، «فردا چه لازم دارم»، ارتباط با مشاور |
| ولی (پدر/مادر/قیم؛ والدین جدا هر دو مستقل) | «امروز فرزندم»، سوییچر فرزندان، حضور/نمره/برنامه **رایگان**، موجه‌کردن غیبت با یک دکمه، مرخصی (روزانه/ساعتی/چندروزه)، نوبت ملاقات، پیام، کمک داوطلبانه یا شهریه |
| نگهبان/انتظامات | ثبت ورود/خروج مراجعین، خروج زودهنگام دانش‌آموز با مرخصی تأییدشده |
| مربی بهداشت | هشدار سلامت/حساسیت روی پرونده |
| کتابدار/امین اموال | امانت کتاب، اموال/کارگاه |
| مؤسس (غیردولتی) | گزارش مالی و عملکرد کلان |
| رئیس اداره (منطقه/استان) | داشبورد تجمیعی، بخشنامهٔ گروهی، شناسایی مدارس کم‌برخوردار |

اصل معماری: «عامل اجرایی» با **چک‌لیست مجوز قابل‌ترکیب** (نه ۱۵ نقش سخت‌کد). Person → Account → Roles.

## ۴. چرخهٔ یک سال تحصیلی و موقعیت‌های غیرعادی

| ماه | رویداد | نیاز |
|---|---|---|
| شهریور (پیش از سال) | ساماندهی نیرو، کلاس‌بندی، برنامهٔ هفتگی، انتقال سال قبل | ارتقای خودکار پایه، بازگشایی سال جدید بی از دست رفتن سابقه |
| مهر | شروع، کتاب، تثبیت کلاس | ورود دسته‌ای اکسل **با امکان اصلاح هر ردیف** |
| آبان | میان‌نوبت، انجمن اولیا | صورتجلسه |
| آذر–دی | افت تحصیلی، **امتحانات نوبت اول** (دوازدهم نهایی) | برنامهٔ امتحان، حوزه، مراقب، «غ» |
| دی–بهمن | **تعطیلی/غیرحضوری ناگهانی** (آلودگی هوا، مدیریت انرژی، آنفلوانزا — اعلام شب قبل، استانی/شهری، «دو نوبت صبح و عصر») | علامت‌زدن روز تعطیل/غیرحضوری ⇒ غیبت نخورد، اعلان فوری به اولیا، جابه‌جایی امتحان |
| بهمن | کارنامهٔ نوبت اول | انتشار پس از تأیید |
| اسفند | **پیش‌ثبت‌نام سال بعد وسط سال جاری** | دو سال هم‌زمان |
| فروردین | نوروز، آزمون آزمایشی نهم/دوازدهم | تقویم تعطیلات |
| اردیبهشت–خرداد | نوبت دوم، نهایی یازدهم/دوازدهم (در ۱۴۰۵ به تیر–مرداد منتقل شد) | تقویم امتحان قابل جابه‌جایی |
| تیر | هدایت تحصیلی نهم، فارغ‌التحصیلی | فرم هدایت |
| مرداد–شهریور | تجدیدی/شهریور، جابه‌جایی مدرسه، بستن سال | گردش کار تجدیدی، انتقال، بایگانی |

موقعیت‌های دیگر: قطع اینترنت/فیلترینگ (کار کامل بدون VPN)، گوشی مشترک خانواده، ولی بی‌سواد (متن ساده/پیامک)، والدین جدا، قیم غیروالد، دانش‌آموز انتقالی وسط سال، دبیر مشترک بین دو مدرسه، معلم حق‌التدریس، تغییر شمارهٔ همراه، غیبت طولانی پزشکی، خروج زودهنگام با ولی، حادثه/اورژانس.
