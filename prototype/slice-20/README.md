## چه چیزی اثبات **نمی‌شود**

- **ظرفیت تولید**: عدد ظرفیت این نمونه «یک فرایند روی همین ماشین» است، نه ظرفیت محصول (D‑11).
  هیچ تعهد SLA، RPO/RTO یا هزینهٔ کل از این اجرا استخراج نمی‌شود.
- آزمون روی شبکه/دیتاسنتر واقعی، SQLite/PostgreSQL واقعی، HA چند‌منطقه‌ای، و قیمت واحد میزبان (**O‑HOST**).
- **جداسازی چندمستأجری در محصول** (سقف پلن، grace/suspended/expired، ابطال مجوز اضطراری، استفادهٔ متقابل توکن سطح A/B)
  ⇒ ردیف **۲۰‑ب**، بلوکه تا وجود `tenant_id` در محصول (F‑04).
