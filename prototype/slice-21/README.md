## چه چیزی اثبات می‌شود

| ادعا | چگونه |
|---|---|
| مهاجرت ۹ گامی بدون پرش | ترتیب گام‌ها در کد اجباری است؛ فراخوانی گام ۴ پیش از ۳ ⇒ `step_out_of_order` |
| کپی سایه + نوشتن مضاعف | نوشتن در پنجرهٔ مهاجرت در هر دو مسیر می‌نشیند و در گام ۴ تطبیق داده می‌شود |
| تطبیق داده (counts+hash) | ۴ مجموعه با شمارش و SHA مقایسه می‌شوند؛ یک ردیف اختلاف ⇒ `reconcile_mismatch` و **توقف** |
| عدم‌تطبیق ⇒ هیچ حذفی، مسیر قدیم مرجع | ردیف‌ها دست‌نخورده می‌مانند؛ `rollback` خواندن را به مسیر قدیم برمی‌گرداند |
| RLS در قرنطینه | مستأجر دوم صفر ردیف می‌بیند و ردیف‌های مستأجر اول کامل‌اند ⇒ نشت صفر |
| کلید مستأجر | بکاپ‌ها با کلید تازه بازرمزنگاری می‌شوند؛ کلید قدیمی رد و AAD جابه‌جایی مستأجر را می‌شکند |
| سوئیچ خواندن و حذف مسیر قدیم | سوئیچ فقط با هش برابر؛ حذف مسیر قدیم پیش از ۷ روز پایداری ممنوع و پس از آن **آرشیو** (نه حذف داده) |
| گزارش مهاجرت | همهٔ فیلدهای الزامی §۳.۳ + `step_results` هر ۹ گام + SHA گزارش در audit |
| go/no‑go پایلوت | فقط با «عکس لحظه‌ای سنجه‌های اندازه‌گیری‌شده»؛ P0 ⇒ freeze، P1 ⇒ توقف، P2 ⇒ هشدار بدون توقف |
| پله‌به‌پله و برگشت‌پذیر | موج‌ها ۱→۱۰→۵۰→۲۰۰؛ پرش ناممکن؛ `rollbackWave` فقط آخرین موج را برمی‌گرداند |
| override فقط مالک + دلیل | بدون دلیل رد؛ P0 حتی با override قابل عبور نیست؛ اثر انگشت تصمیم در audit |
| بازیابی: بررسی پیش از نوشتن | امضای مانیفست (Ed25519) + SHA پاکت + تطبیق محتوا در قرنطینه ⇒ در هر شکست **صفر ردیف** نوشته می‌شود |
| swap اتمی + W1 | محتوا برابر مانیفست و همهٔ نشست‌های مستأجر باطل می‌شوند |
| آشتی پس از بازیابی | outbox: `applied` / `conflicted` / `lost` (پنهان نمی‌شود) + `rejected_protected_tables` |
| بستن F‑02 در نمونه | بکاپ کلاینت هرگز روی `users/sessions/audit` نوشته نمی‌شود؛ ارتقای نقش رخ نمی‌دهد |
| rollback با snapshot | بازگردانی وضعیت پیش از موج، با هش برابر snapshot |

## چه چیزی اثبات **نمی‌شود**

- مهاجرت **کد محصول** است و پیش از Gate فاز ۳ اجرا نمی‌شود؛ این نمونه فقط طراحی را با آزمون اجرایی می‌سنجد (۱۶‑ب §۳.۲).
- زمان واقعی قطعی‌صفر، RPO/RTO تولید (هدف‌اند نه اندازه‌گیری)، و اجرای روی PostgreSQL/SQLite واقعی.
- جداسازی چندمستأجری محصول (سقف پلن، grace/suspended/expired، ابطال مجوز اضطراری) ⇒ ردیف **۲۰‑ب**، بلوکه تا F‑04.
- وضعیت‌های اشتراک (`grace/suspended/expired`) و چرخهٔ D‑22 جز در حد برچسب سنجه نشده‌اند.
