# پایش — لوکال (Payesh Local)

نسخهٔ **درون‌مدرسه‌ای** سامانهٔ مدیریت مدرسهٔ «پایش» — بدون سرور ابری، بدون هزینهٔ ماهانه، روی یک سیستم داخل مدرسه.

> این مخزن در فاز **طراحی و تحلیل** است. کد اجرایی هنوز نوشته نشده؛ اسناد زیر نتیجهٔ بازبینی کامل مخزن اصلی (`rezaa2544/p2`) و طرح پیاده‌سازی نسخهٔ لوکال است.

## خلاصهٔ یک‌پاراگرافی

پایش اصلی یک SIS کامل با رابط فارسی/RTL و تقویم جلالی است: ۹ نقش، ۸۷ مجموعه‌داده، ~۹۱ ماژول کلاینت (۳۴ هزار خط) و یک سرور ۵۱ هزار خطی که برای **۱۰ میلیون کاربر** و چندمدرسه‌ای ساخته شده (PostgreSQL + Redis + WAF + canary + multi-tenant + DR). کلاینت آن **آفلاین‌محور و تک‌فایلی** است (`index.html` ۱٫۷ مگابایتی بدون هیچ وابستگی خارجی) و همین، بهترین نقطهٔ شروع برای نسخهٔ لوکال است. پیشنهاد: **کلاینت را نگه داریم، سرور ملی را کنار بگذاریم و یک «سرور مدرسه» سبک (Node + SQLite) با همان قرارداد API بنویسیم** که روی یک مینی‌پی‌سی داخل مدرسه اجرا می‌شود و از طریق Wi-Fi مدرسه به گوشی دبیران/دانش‌آموزان/اولیا سرویس می‌دهد — کاملاً مستقل از اینترنت، با پشتیبان‌گیری شبانه روی فضای ابری رایگان.
